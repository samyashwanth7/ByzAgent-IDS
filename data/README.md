# Dataset Download Instructions

## CICIDS 2017 (Primary Dataset)

### Option 1: Kaggle (Recommended — Easiest)
1. Go to: https://www.kaggle.com/datasets/ciaboricmendez/cicids2017
2. Download the CSV files
3. Place all CSV files in this `data/raw/` directory

### Option 2: Official UNB Source
1. Go to: https://www.unb.ca/cic/datasets/ids-2017.html
2. Download the "MachineLearningCVE" folder
3. Place all CSV files in `data/raw/`

### Expected Files in `data/raw/`:
- `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv`
- `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv`
- `Friday-WorkingHours-Morning.pcap_ISCX.csv`
- `Monday-WorkingHours.pcap_ISCX.csv`
- `Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv`
- `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`
- `Tuesday-WorkingHours.pcap_ISCX.csv`
- `Wednesday-workingHours.pcap_ISCX.csv`

## NSL-KDD (Secondary Dataset)
1. Download from: https://www.unb.ca/cic/datasets/nsl.html
2. Place `KDDTrain+.csv` and `KDDTest+.csv` in `data/raw/`

## UNSW-NB15 (Tertiary Dataset)
1. Download from: https://research.unsw.edu.au/projects/unsw-nb15-dataset
2. Place CSV files in `data/raw/`
